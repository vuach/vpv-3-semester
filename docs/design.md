# Конструкция и измерительный тракт

| Узел | Конфигурация |
|---|---|
| Платформа | Creality Ender 3, перемещение по G-code без нагрева |
| Крепление | Съёмный кронштейн на два М4, межосевое расстояние 62,25 мм, примерочный вынос от оси сопла 50 мм |
| Датчик V1 | Воздушная катушка, 160 витков ПЭТВ-2 0,16/0,19 мм, диаметр намотки около 13 мм. Расчётные ориентиры — 5 Ом и 0,31 мГн. |
| Эталон | Неподвижная катушка над целым образцом того же сплава и толщины |
| Измерение | Hantek DSO2D15 возбуждает обе ветви. CH1 регистрирует усиленную разность, CH2 — опорный сигнал. |
| EDC-AMP V1 | Две ветви по 100 Ом, усилитель AD8421, питание ±9 В, усиление ×1 / ×10,9 / ×20,84 / ×50,5. Замкнута максимум одна ветвь выбора усиления. |
| Образец | Планируется алюминий 150 × 150 × 2 мм, отверстия Ø3/6/10 мм и прорези 25 мм шириной 1/2/4 мм. Обратные канавки требуют отдельной обработки. |

Над целым участком отдельно измеряем изменение комплексного отклика с зазором. Затем сравниваем этот вклад с откликом дефекта и разбросом между проходами.

В каталоге `schematics/` лежат предварительный эскиз и экспорт EasyEDA. Перед заказом платы нужно сверить распиновку, соединения, посадочные места и номиналы с артикулами в BOM.
